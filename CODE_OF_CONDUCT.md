# Code of conduct / Code de conduite

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful, inclusive and constructive. Report unacceptable behaviour to the maintainers.

Ce projet suit le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
Faites preuve de respect, d’inclusion et d’esprit constructif. Signalez tout comportement inacceptable aux
responsables du projet.
